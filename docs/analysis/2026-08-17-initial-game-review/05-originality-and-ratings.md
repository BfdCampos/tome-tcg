# Originality & ratings

My ratings of the game itself. Each dimension **/100**.

| Dimension | Score | Reasoning |
|---|---:|---|
| **Originality** | **82** | The double-layer colour-RPS (field *and* attack) plus persistent per-colour stacks where only the top card is live is a combination not found in any existing TCG researched. It borrows recognizable atoms (colour wheel, simultaneous reveal, stacking) but assembles them into something that feels new. Loses points only because each *individual* atom exists elsewhere. |
| **Complexity / barrier to entry** | **34** | Where **modern 2026 Yu-Gi-Oh ≈ 100** (30-minute combo turns, hundreds of interrupts). Tome's rules fit on a card; a new player is competent in one game. The *skill ceiling* (reading opponents, stack sequencing) is higher than the *learning floor* — a very healthy profile for mobile. |
| **Decision density per turn** | **58** | Two meaningful simultaneous choices (which field, which colour) + the one-card-per-turn tempo fork. Rich for its weight, but the hard 1-card/turn cap and 3 colours bound how deep any single decision goes. |
| **Mind-game / bluff depth** | **76** | The standout. Because only the clash winner connects and choices are simultaneous, every turn is a Yomi-style read. Very high for a card game. |
| **Elegance / rules-to-depth ratio** | **80** | Enormous emergent depth from a tiny ruleset (one wheel drives everything). The game's best quality. |
| **Mobile / one-thumb fit** | **85** | 3 stacks + 1 field + a single prepare choice maps almost perfectly to a vertical 3-slot, tap-to-commit interface. The design is *natively* mobile in a way ported TCGs aren't. |
| **Snowball / comeback balance (as-built)** | **45** | Stacks and fields (Fired Up, Overgrown Root) snowball hard, and "only winner deals damage" makes swings huge; comeback tools (Last Resort, heals, field removal) exist but aren't yet tuned. Needs balance data. |

## Headline take

The *concept* is genuinely original and unusually elegant, and it's the rare TCG
that was clearly *designed for the phone rather than ported to it*. The distance to
launch is almost entirely **production** (AI opponent, mobile packaging,
implementing/illustrating the card backlog, balance, live-ops) rather than
**design** — plus the two engine fixes noted in the completion-status doc (both
since done).
